# Luxury Component Library Documentation

## 1. Shared Visual Primitives
* **LuxuryButton:** Premium CTA button styling with custom shimmer background animations.
* **GlassCard:** Transparent panels with backdrop blur and gold borders.
* **LoadingSkeleton:** Gradients representing skeleton UI placeholders.
* **LuxuryInput:** Inputs with floating labels and animated gold underlines on focus.

## 2. Media Upload Elements
* **FileUploader:** Reusable drag-and-drop element supporting image thumbnail previews, size validation checks, and upload progress displays.

## 3. Administrative Layouts
* **AdminLayout:** Sidebar layout providing desktop drawers and mobile top navigation menus for administrators.
